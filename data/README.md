# Sample data — synthetic, not real

Every file in this folder (`customers.csv`, `orders.csv`, `app_events.csv`, `returns.csv`,
`reviews.csv`, `catalogue.csv`) is **generated**, not real Dhaga & Co. data — a composite built
from how businesses of this kind actually run, shaped to match the real numbers cited in the
client-engagement brief.

Generated by [`generate_mock_data.py`](generate_mock_data.py) with a fixed seed (`random.seed(7)`),
so it's reproducible — run `python data/generate_mock_data.py` to regenerate it identically.
It's deliberately shaped like the messy, realistic data the brief describes, not curated
happy-path rows:

| | Current sample | Brief's real numbers |
|---|---|---|
| Customers | 75 | — |
| Catalogue | 150 SKUs | ~14,000 SKUs |
| Orders | 224 | ~11,000,000 |
| Distinct colour spellings | 75 | ~90 |
| Returns landing in "Other" free text | ~38% | 44% |
| Search phrases | Hinglish/occasion ("mehndi function dress", "office wear kurti") | same |

If this ever gets confused for real data — in a demo, in a screenshot, in a commit message —
that's a mistake to fix immediately, not a detail to let slide.
